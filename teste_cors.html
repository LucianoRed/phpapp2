REQ 14

CORS at the Gateway origin: …

Demonstrate that calling a backend on a different origin from the browser is blocked by CORS, and that routing the same call through RHCL / Gateway API fixes it by adding the right Access-Control-* headers.

Scenario

[browser @ this page origin]
        |
        |  fetch(URL below)
        v
[ direct backend ]   --> blocked: no CORS headers
[ via RHCL gateway ] --> allowed: gateway sets Access-Control-Allow-Origin
Read this first. When CORS blocks a request, JavaScript only sees a generic TypeError: Failed to fetch. The detailed "No 'Access-Control-Allow-Origin' header is present" message is printed by the browser itself and only shows up in the DevTools Console (F12) and the Network tab. Keep DevTools open while running this test.
